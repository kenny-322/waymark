# WAY●MARK — интерактивный планировщик путешествий

**WAY●MARK** — учебный веб-проект для исследования городов мира на интерактивном 3D-глобусе и составления маршрутов путешествий.

> **Текущая версия:** 1.30  
> **Города в каталоге:** 215  
> **Технологии:** HTML, CSS, JavaScript, Three.js

## Возможности

- **Интерактивный 3D-глобус.** Можно вращать Землю, приближать и отдалять её, изучать расположение городов.
- **Каталог из 215 городов.** Для города предусмотрены страна, координаты, флаг, описание, язык, валюта, сведения о климате и кухне, сезон для посещения, демонстрационная погода и не менее шести достопримечательностей.
- **Поиск городов.** Введите название города и выберите результат. Глобус переместится к выбранному городу.
- **Построение маршрута.** Выберите место отправления, затем город назначения и подходящий транспорт. Маршрут можно продолжать несколькими участками.
- **Выбор транспорта.** Сайт сравнивает самолёт, поезд, автомобиль, автобус и корабль там, где соответствующий вариант доступен.
- **Оценка поездки.** Показываются приблизительные расстояние, время в пути и стоимость.
- **«Удиви меня».** Автоматический подбор маршрута по шаблонам: случайный, экономичный, тёплый климат, культурный, мировые мегаполисы и гастрономический. Доступны фильтры по климату, бюджету, числу городов, сезону, темпу, транспорту и популярности.
- **«Моё путешествие».** Составленный маршрут можно сохранить и открыть позднее в том же браузере.
- **Конвертер валют.** Позволяет пересчитать сумму между валютами, используемыми в каталоге.
- **Адаптивный интерфейс.** На узких экранах и сенсорных устройствах включается мобильный вариант интерфейса.
- **Мобильное управление.** Вращение одним пальцем, масштабирование двумя пальцами и адаптивная чувствительность свайпа в зависимости от масштаба.

## Как пользоваться сайтом

1. Откройте вкладку **«Карта»** и найдите нужный город на глобусе или через строку поиска.
2. Выберите первый город — он станет точкой отправления.
3. Выберите второй город. Откроется панель вариантов транспорта для этого направления.
4. Выберите доступный транспорт и изучите примерное время и стоимость маршрута.
5. Продолжайте добавлять участки путешествия в пределах установленного приложением лимита. Если нужно начать заново, используйте действие создания нового путешествия.
6. Сохраните готовое путешествие и найдите его во вкладке **«Моё путешествие»**.
7. Чтобы получить автоматически составленный вариант, откройте **«Удиви меня»**, выберите шаблон и при необходимости задайте фильтры, затем нажмите **«Составить маршрут»**.

## Управление глобусом

### Компьютер

- **Зажать левую кнопку мыши и перемещать указатель** — вращать глобус.
- **Колесо мыши** — приближать и отдалять глобус.
- В текущей версии сохранены отдельные параметры вращения и масштаба для настольного интерфейса.

### Телефон или планшет

- **Свайп одним пальцем** — вращать глобус.
- **Сведение и разведение двух пальцев** — отдалять и приближать.
- При приближении к поверхности чувствительность свайпов постепенно уменьшается, чтобы было легче выбирать близко расположенные города.
- Горизонтальное вращение не ограничено, а наклон по вертикали ограничен, чтобы глобус не переворачивался вверх ногами.
- При выборе города из поиска камера плавно наводится на него.

## Как запустить локально

Не рекомендуется запускать проект простым открытием `index.html` двойным щелчком: браузер может заблокировать импорт JavaScript-модулей. Запустите локальный HTTP-сервер.

### Windows

1. Распакуйте файлы проекта в одну папку.
2. Откройте эту папку в VS Code.
3. Откройте терминал (**Terminal → New Terminal**).
4. Выполните одну из команд:

   ```powershell
   py -m http.server 8000
   ```

   Если команда `py` недоступна, попробуйте:

   ```powershell
   python -m http.server 8000
   ```

5. Пока терминал работает, откройте в браузере адрес [http://localhost:8000](http://localhost:8000).
6. Чтобы остановить сервер, вернитесь в терминал и нажмите **Ctrl+C**.

## Публикация на GitHub Pages

1. Загрузите в корень репозитория файлы `index.html`, `style.css`, `script.js`, `city-data.js` и `transport-data.js`, а также `README.md`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе сборки выберите публикацию из ветки (обычно `main`) и папку `/ (root)`.
4. Сохраните настройки и дождитесь, пока GitHub Pages опубликует сайт.
5. Откройте адрес сайта, указанный в настройках Pages. После обновления файлов перезагрузите сайт с очисткой кэша, например **Ctrl+F5** на компьютере.

Важно: загружать следует сами файлы проекта, а не только ZIP-архив. Сохраняйте резервную копию предыдущей рабочей версии перед заменой файлов.

## Как добавить город

Основные сведения о городах хранятся в `city-data.js` внутри массива `CITY_DATA`. Для добавления города:

1. Добавьте новый объект в `CITY_DATA`.
2. Назначьте уникальный `id` на латинице — он используется при поиске, построении маршрутов и сохранении путешествий.
3. Заполните обязательные поля по образцу существующих записей: `id`, `name`, `country`, `flag`, `lat`, `lon`, `timezone`, `currency`, `language`, `popularity`, `weather`, `description`, `attractions`, `bestTime`, `climate` и `cuisine`.
4. Укажите корректные географические координаты: широта `lat` должна находиться в диапазоне от −90 до 90, долгота `lon` — от −180 до 180.
5. Добавьте не менее шести достопримечательностей в массив `attractions`. Каждый элемент содержит название и короткое описание.
6. Проверьте, что у города уникальные `id` и координаты, а все обязательные данные заполнены.
7. Если для направления нужна специальная доступность поезда, автомобиля, автобуса или корабля, при необходимости обновите соответствующие соединения в `transport-data.js`. Самолёт обрабатывается как универсальный вариант маршрута.

Поиск и метки формируются на основе `CITY_DATA`, поэтому для простого добавления города обычно не требуется менять HTML-разметку или создавать отдельные элементы интерфейса вручную.

## Данные и ограничения

WAY●MARK — учебный демонстрационный проект, а не система бронирования или сервис актуальных туристических данных.

- **Погода и сведения о городах** хранятся в файле каталога и не обновляются в реальном времени.
- **Стоимость и продолжительность поездок** рассчитываются по условным параметрам транспорта. Они не являются котировками перевозчиков и могут существенно отличаться от реальных.
- **Курс валют в конвертере** задан внутри `script.js` в таблице `CURRENCY_TO_RUB`; это фиксированные ориентировочные значения, а не live-курсы. Перед реальной поездкой проверяйте актуальный курс отдельно.
- **Сохранённые путешествия** находятся в локальном хранилище браузера (`localStorage`) на текущем устройстве. Они не синхронизируются между устройствами или разными браузерами. Очистка данных сайта может удалить сохранённые маршруты.
- **Серверной части и учётных записей** в этой версии нет.
- Текстуры Земли и библиотека Three.js загружаются с внешних ресурсов, поэтому их доступность зависит от подключения к интернету и доступности CDN.

## Если сайт не запускается

- Убедитесь, что сервер запущен и страница открыта через `http://localhost:8000`, а не через `file:///...`.
- Проверьте, что все пять файлов приложения лежат рядом и называются именно так, как указано в разделе структуры проекта.
- Проверьте интернет-соединение: Three.js и текстуры загружаются извне.
- Если после обновления GitHub Pages показывается старая версия, выполните жёсткую перезагрузку страницы или откройте её в приватном окне.
- Если глобус не отображается, проверьте поддержку WebGL и сообщения об ошибках в консоли разработчика браузера.
