# WAY●MARK 1.26 — Mobile interaction refinements

This build refines mobile interaction based on feedback while preserving the 1.25 project structure and travel-planning features.

## Added in 1.26
- Touch swipe rotation is about 22% faster; mouse drag behavior is unchanged.
- Pinch-to-zoom and mouse-wheel zoom can now move farther out, up to camera distance 7.6.
- Selecting a city from search smoothly rotates the globe to bring that city to the front and eases to a comfortable mid zoom (4.85).

## Preserved
- City catalog and city data files.
- Transport connections, route-building logic and saved journeys.
- Surprise route generator and existing desktop/mobile layouts.
- Earth textures, city markers and labels.

## Testing note
- JavaScript syntax and archive integrity were checked.
- Real-device testing is still recommended for touch feel and search transitions.
